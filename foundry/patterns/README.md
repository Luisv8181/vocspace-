# Foundry Patterns

Accommodation patterns are reusable hypotheses about ways to change tasks, environments, tools, interfaces, or supports to address functional barriers.

Start with `src/data/accommodation-patterns.js` for the initial synthetic pattern set. These entries are original VocSpace synthesis and are marked draft. They are not yet validated or represented as clinical/legal conclusions.

Before creating new patterns, read `docs/ACCOMMODATION-KNOWLEDGE-STRATEGY.md` and `docs/EVIDENCE-AND-SOURCE-PROVENANCE.md`.
