# Open-Source Research Philosophy

VocSpace should be more than an application repository.

It can become an open research notebook for rehabilitation counseling technology.

## Artifacts that belong here

- design patterns
- accommodation recipes
- synthetic cases
- accessibility component examples
- research protocols
- evaluation instruments
- coding-agent prompts
- implementation examples
- datasets with appropriate provenance and licensing
- literature maps
- case simulations
- accessibility experiments

## Accommodation Recipe

A reusable recipe can contain:

1. Barrier
2. Functional need
3. Context
4. Candidate interventions
5. Evidence/source
6. Implementation approach
7. Technical example
8. Validation criteria
9. Observed outcome

This creates a bridge between counseling knowledge and programmable systems.

## Lived experience

People with disabilities should be contributors and evaluators, not merely test subjects.

The project should seek participatory design and feedback before treating a solution as successful.

## Research-to-product loop

**Question → Prototype → Test → Document → Release → Evaluate → Improve**

This loop should remain visible in the repository.
