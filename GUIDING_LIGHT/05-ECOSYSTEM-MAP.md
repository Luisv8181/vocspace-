# VocSpace Ecosystem

VocSpace is intentionally an ecosystem layer.

It should connect people to specialized resources rather than attempting to own every solution.

## Resource types

**Knowledge**
- JAN
- accessibility standards
- government guidance
- professional organizations

**Technology**
- TechA11y
- assistive technology vendors
- accessibility testing tools
- adaptive hardware
- speech and language tools

**People**
- CRCs
- vocational experts
- accessibility specialists
- occupational therapists
- developers
- employers
- disability advocates

**Services**
- vocational rehabilitation
- employment programs
- accessibility consulting
- technology implementation

**Builders**
- developers
- no-code creators
- AI coding agents
- researchers
- students

## Routing principle

VocSpace should ask:

> Who or what is best positioned to solve this particular barrier?

That could lead outward from VocSpace.

That is a feature, not a failure.

## TechA11y relationship

TechA11y is an example of a specialized ecosystem partner.

Where a case involves web accessibility auditing/remediation, VocSpace can point toward TechA11y rather than recreating its product.

VocSpace can instead concentrate on the upstream and downstream layers:

**Person/context → barrier → functional need → solution selection → resource routing → implementation → validation**
