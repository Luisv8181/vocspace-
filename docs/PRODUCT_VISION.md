# VocSpace Product Vision

## North Star

VocSpace helps people and organizations turn accessibility and accommodation needs into actionable solutions.

The core workflow is:

**Barrier → Need → Options → Solution → Connection → Implementation → Validation**

VocSpace is not an accessibility overlay, a generic resource directory, or a replacement for qualified professionals. It is a coordination and intelligence layer that helps identify the problem, explain the functional need, discover credible solution pathways, and connect the right people, tools, and services.

## The Core Question

Instead of asking only:

> What accommodation do you want?

VocSpace asks:

> What are you trying to do, what is getting in the way, and what changes could make the task possible?

This preserves the rehabilitation counseling lens of person + environment + task + intervention.

## Initial Domains

1. Employment accommodations
2. Digital accessibility
3. Workplace/environmental accessibility
4. Customer/community accessibility
5. Assistive technology and adaptive tools

Employment and public/customer accessibility must remain distinct workflows because their legal and operational contexts differ.

## Ecosystem Principle

VocSpace does not need to build every solution.

It should know when to:
- provide guidance
- surface a credible external resource
- recommend a specialist
- generate a communication/request artifact
- generate an implementation specification
- generate a coding-agent prompt
- facilitate a conversation
- evaluate whether the solution worked

External resources can include JAN, TechA11y, accessibility standards, assistive technology providers, vocational rehabilitation resources, and qualified professionals.

## Guardrails

Every recommendation should preserve:
- source/provenance
- rationale
- confidence
- applicability/context
- implementation pathway
- validation method

Legal requirements, professional guidance, accessibility standards, and implementation suggestions must not be presented as interchangeable.
