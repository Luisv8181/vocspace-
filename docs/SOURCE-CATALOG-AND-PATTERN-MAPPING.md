# Source Catalog and Pattern Mapping

## Purpose

The VocSpace source catalog records specialist sources to consult. It does not reproduce their articles. Source presence does not mean every statement in a related pattern is verified.

## Source records

The initial JAN source records are in `src/data/source-catalog.js`. Links point directly to JAN pages and are intended for source discovery, not content mirroring.

## Current pattern links

The initial mappings are explicitly provisional:

- **AP-001 Reduce competing information** → JAN's page on distracting workspaces. Relevant as an example of considering environmental options; not evidence for every digital pattern.
- **AP-002 Support task resumption** → JAN accommodation monitoring guidance. Relevant to reviewing continued effectiveness; does not establish that task-resumption aids are effective.
- **AP-003 Improve website orientation** → JAN's effective communication topic page. Discovery link only; technical accessibility claims require appropriate standards, evaluation, and separate sources.
- **AP-004 Reduce physical grip demand** → JAN's grip/grasping article. Discovery source for accommodation ideas; any generated physical device still needs risk-appropriate testing and review.
- **AP-005 Make communication more accessible** → JAN's accommodation-process communication article and effective-communication topic page. Applicability depends on the interaction and legal/technical context.

These are candidate reading paths, not completed evidence reviews. Patterns remain `draft` and the provenance class remains `vocspace-synthesis`.

## Promotion rule

Do not change a pattern to `source-reviewed` merely because a source ID is attached. A human reviewer must record:

- The specific claim the source supports
- Relevant wording or pinpoint location within the source
- Applicability and limits
- Conflicting or missing evidence
- Reviewer and review date
- Whether the pattern remains a hypothesis, has source support, or has been tested

JAN's content must be used according to applicable terms. VocSpace should link users to the source and write its own pattern descriptions instead of bulk-copying or redistributing JAN articles.
